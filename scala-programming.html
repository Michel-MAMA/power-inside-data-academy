Module 2: Collections & Immutabilité
List, Set, Map, Tuple et opérations de transformation
// Collections immuables val list = List(1, 2, 3, 4, 5) val set = Set(1, 2, 2, 3) // Set(1, 2, 3) val map = Map("a" -> 1, "b" -> 2) // Transformations (retournent nouvelles collections) val doubled = list.map(_ * 2) // List(2, 4, 6, 8, 10) val evens = list.filter(_ % 2 == 0) // List(2, 4) // Réduction val sum = list.reduce(_ + _) // 15 val product = list.fold(1)(_ * _) // 120 // Chaînage val result = list .filter(_ > 2) .map(_ * 10) .sum // 300

Module 3: Programmation Fonctionnelle
Higher-Order Functions, Closures, Currying et Composition
// Fonctions comme valeurs val add = (a: Int, b: Int) => a + b val result = add(3, 5) // 8 // Higher-order function def applyOperation(x: Int, y: Int, f: (Int, Int) => Int): Int = { f(x, y) } // Utilisation val res1 = applyOperation(5, 3, add) // 8 val res2 = applyOperation(5, 3, (a, b) => a * b) // 15 // Currying def multiply(a: Int)(b: Int): Int = a * b val double = multiply(2) _ // Fonction partielle val res3 = double(5) // 10 // Composition def compose[A, B, C](f: A => B, g: B => C): A => C = { a => g(f(a)) }

Module 4: Case Classes & ADT (Algebraic Data Types)
Structures de données, sérialisation et pattern matching avancé
// Case class (données immuables) case class Person(name: String, age: Int) { def info: String = s"$name ($age ans)" } // Créer et utiliser val person = Person("Alice", 25) person.copy(age = 26) // Person("Alice", 26) // Sealed traits pour ADT sealed trait Result[+T] case class Success[T](value: T) extends Result[T] case class Failure(error: String) extends Result[Nothing] // Pattern matching sur ADT def handleResult[T](result: Result[T]): String = result match { case Success(value) => s"OK: $value" case Failure(error) => s"Erreur: $error" }

Module 5: Traits, Mixins & Implicits
Composition, mixins et paramètres implicites pour architectures flexibles
// Traits comme interfaces et mixins trait Loggable { def log(msg: String): Unit = println(s"[LOG] $msg") } trait Serializable { def toJson: String } // Classe avec mixins multiples class Service extends Loggable with Serializable { override def toJson = """{"status":"ok"}""" def process(): Unit = { log("Processing...") } } // Implicits (paramètres automatiques) implicit val defaultName: String = "Unknown" def greet()(implicit name: String): Unit = { println(s"Hello $name") } greet() // Utilise defaultName automatiquement
❌ Sans Mixins
class A { ... } class B { ... } // Impossible de combiner
✅ Avec Traits
class C extends A with B // Flexible & composable
