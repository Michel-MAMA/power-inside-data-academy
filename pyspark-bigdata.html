Module 2: Transformations et Actions
Map, Filter, Reduce et les opérations Spark essentielles
# Transformations sur RDD rdd = sc.parallelize([1, 2, 3, 4, 5]) # Map: transformer chaque élément rdd_squared = rdd.map(lambda x: x ** 2) # Filter: sélectionner des éléments rdd_even = rdd.filter(lambda x: x % 2 == 0) # Actions: récupérer les résultats result_map = rdd_squared.collect() # [1, 4, 9, 16, 25] result_filter = rdd_even.collect() # [2, 4]

Module 3: Agrégations et GroupBy
Grouper, agréger et analyser les données avec Spark
# Données de ventes data = [ ("Laptop", "Électronique", 1200), ("Chaise", "Meubles", 150), ("Téléphone", "Électronique", 800), ] df = spark.createDataFrame(data, ["produit", "categorie", "prix"]) # Grouper par catégorie et calculer le prix moyen df.groupBy("categorie").avg("prix").show() # Compter les produits par catégorie df.groupBy("categorie").count().show()

Module 4: Joins et Relations
Fusionner des DataFrames et gérer les relations complexes
# DataFrame 1: Employés df_employes = spark.createDataFrame([ (1, "Alice", 10), (2, "Bob", 10), (3, "Charlie", 20) ], ["id_emp", "nom", "dept_id"]) # DataFrame 2: Départements df_depts = spark.createDataFrame([ (10, "IT"), (20, "HR") ], ["dept_id", "nom_dept"]) # Inner Join df_joined = df_employes.join(df_depts, "dept_id", "inner") df_joined.show()

Module 5: Optimisation et Performance
Caching, Partitioning et best practices Spark
# Lire les données df = spark.read.parquet("data.parquet") # Cacher le DataFrame en mémoire df.cache() # ou df.persist() # Partitionner les données df_partitioned = df.repartition(10, "date") # Exécuter des opérations result = df.filter(df.age > 25).groupBy("ville").count() result.show() # Libérer le cache df.unpersist()
