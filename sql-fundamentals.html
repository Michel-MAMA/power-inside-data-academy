SQL Fondamentaux

Maîtrisez le langage SQL — de la récupération de données simples aux requêtes complexes avec JOIN, agrégation et sous-requêtes. Apprenez en écrivant vos propres requêtes.

Module 1 · SELECT et Filtrage

La clause SELECT

SELECT récupère les colonnes. * signifie "toutes les colonnes".

SELECT colonne1, colonne2 FROM table_name;

WHERE — Filtrer les lignes

La clause WHERE filtre les résultats selon des conditions :

  • = — Égal à
  • != ou <> — Différent de
  • >, <, >=, <= — Comparaisons
  • BETWEEN — Entre deux valeurs
  • IN — Dans une liste
  • LIKE — Recherche de texte avec % et _
  • AND, OR, NOT — Combinaisons logiques

Module 2 · Joindre des tables (JOIN)

Types de JOIN

Les JOIN combinent des lignes de plusieurs tables :

  • INNER JOIN — Lignes qui correspondent dans les deux tables
  • LEFT JOIN — Toutes les lignes de gauche + correspondances
  • RIGHT JOIN — Toutes les lignes de droite + correspondances
  • FULL OUTER JOIN — Toutes les lignes des deux tables

Syntaxe

SELECT ... FROM table1 INNER JOIN table2 ON table1.id = table2.foreign_id

La clause ON spécifie la condition de jointure (habituellement sur les clés primaires/étrangères).

Module 3 · Agrégation et GROUP BY

Fonctions d'agrégation

Résument les données sur un groupe de lignes :

  • COUNT() — Compte le nombre de lignes
  • SUM() — Somme les valeurs
  • AVG() — Moyenne des valeurs
  • MIN(), MAX() — Valeurs min et max

GROUP BY

GROUP BY regroupe les lignes par colonnes spécifiques, puis applique les agrégations :

SELECT dept_id, COUNT(*) FROM employes GROUP BY dept_id;

La clause HAVING filtre les groupes (comme WHERE pour les groupes).

Module 4 · Tri et Pagination

ORDER BY — Trier les résultats

ORDER BY colonne ASC|DESC;

  • ASC — Ascendant (par défaut)
  • DESC — Descendant
  • Supportes plusieurs colonnes : ORDER BY nom ASC, salaire DESC

LIMIT et OFFSET

  • LIMIT n — Retourne les n premières lignes
  • OFFSET m — Saute les m premières lignes
  • LIMIT n OFFSET m — Pagination (page m, taille n)
