Module 2: Régression Linéaire & Prédiction
Régression simple/multiple, coefficients, R² et résidus
📚 Concepts clés:
  • Régression Linéaire: y = a₀ + a₁x₁ + a₂x₂ + ...
  • Coefficients: Poids de chaque feature (importance)
  • Intercept (a₀): Valeur quand toutes features = 0
  • MSE: Erreur moyenne au carré (optimisée)
  • R² Score: 1 = parfait, 0 = mauvais
  • Overfitting: Train score > test score = danger
📝 Code Python
📤 Résultat
Cliquez sur "Exécuter"...
💡 À Retenir:

Régression = prédire valeurs continues. MSE optimisée = moindres carrés. R² = 0-1 (1=parfait). Train/test MSE ≈ bon signe. MSE >> sur test = overfitting. Vérifier résidus ≈ 0 (normalement distribués).

K-Means, hiérarchique, clustering et détection de patterns
📚 Concepts clés:

  • Inertia: Somme distances intra-clusters
  • Silhouette: -1 à 1 (1 = bon clustering)
  • Elbow Method: Trouver K optimal
  • Feature Scaling: Normaliser pour clustering
