Module 2: Programmation Fonctionnelle
Lambda, Map, Filter, Reduce et programmation déclarative.
📚 Concepts clés:
  • Fonctions Lambda: Fonctions anonymes: lambda x: x * 2
  • Map: Applique une fonction à chaque élément: map(func, liste)
  • Filter: Sélectionne les éléments matching une condition: filter(func, liste)
  • Reduce: Agrège les éléments: reduce(func, liste)
  • Avantage: Code plus déclaratif et lisible

📤 Résultat
Cliquez sur "Exécuter"...
💡 À Retenir:

La programmation fonctionnelle permet d'écrire du code plus lisible et déclaratif. Map, Filter, Reduce sont les trois pilliers. Pensez à utiliser les compréhensions (plus Pythonic) quand c'est possible!

Module 3: Programmation Orientée Objet Avancée
Héritage, polymorphisme, encapsulation et décorateurs.
📚 Concepts clés:
  • Héritage: Créer une classe enfant qui hérite d'une classe parent
  • Polymorphisme: Surcharger les méthodes dans les classes enfants
  • Encapsulation: Contrôler l'accès aux attributs (public, protected, private)
  • @property: Créer des attributs avec getters/setters
  • super(): Appeler les méthodes de la classe parent
📝 Code Python
📤 Résultat
Cliquez sur "Exécuter"...
💡 À Retenir:

L'héritage permet de créer des hiérarchies de classes. Le polymorphisme (surcharge de méthodes) permet à chaque classe d'avoir son comportement. L'encapsulation (avec _ et @property) sécurise l'accès aux données. Utilisez super() pour accéder aux méthodes parentes!

Module 4: Gestion des Erreurs & Exceptions
Try-Except, Finally, Custom Exceptions et gestion robuste.
📚 Concepts clés:
  • Try-Except: Attraper et gérer les erreurs
  • Exceptions personnalisées: Créer vos propres erreurs avec class MonErreur(Exception)
  • Finally: Code exécuté même si erreur (nettoyage)
  • Raise: Lever une exception pour le code appelant
  • Else: Bloc exécuté si pas d'erreur
📝 Code Python
📤 Résultat
Cliquez sur "Exécuter"...
💡 À Retenir:

Toujours utiliser try-except pour les opérations risquées (division, conversion, fichiers). Créez des exceptions personnalisées pour votre domaine. N'oubliez pas le finally pour nettoyer les ressources. Une bonne gestion d'erreurs rend le code robuste!

Module 5: Décorateurs & Métaprogrammation
Créez des décorateurs pour modifier le comportement des fonctions.
📚 Concepts clés:
  • Décorateur: Fonction qui modifie une autre fonction: @mon_decorateur
  • Wrapper: Fonction interne qui enveloppe la fonction originale
  • *args, **kwargs: Accepter n'importe quels arguments
  • Stacking: Appliquer plusieurs décorateurs: @deco1 @deco2
  • Cas d'usage: Logging, timing, validation, caching
📝 Code Python
📤 Résultat
Cliquez sur "Exécuter"...
💡 À Retenir:

Les décorateurs sont une forme de métaprogrammation puissante. Ils permettent d'ajouter des fonctionnalités à des fonctions existantes sans les modifier. Pattern: decorateur → wrapper → *args, **kwargs. Cas d'usage: timing, logging, validation, caching, authentification.
