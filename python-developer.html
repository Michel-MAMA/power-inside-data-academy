Module 1 · Fondamentaux Python

Variables et Types de données

En Python, les variables sont déclarées sans type explicite. Python infère le type automatiquement.

Types principaux :

  • int — Nombres entiers : 42, -10, 0
  • float — Nombres décimaux : 3.14, -0.5
  • str — Chaînes de caractères : "Hello", 'Python'
  • bool — Booléens : True, False
  • list — Listes : [1, 2, 3], ['a', 'b']
  • dict — Dictionnaires : {'nom': 'Alice', 'age': 30}

Les variables Python sont dynamiquement typées et peuvent changer de type au cours du programme.

Module 2 · Contrôle de flux et Boucles

Conditions (if/elif/else)

Les conditions permettent d'exécuter du code selon des critères :

  • if condition: — Exécute si la condition est vraie
  • elif condition: — Exécute si précédent if est faux
  • else: — Exécute si aucun if/elif n'est vrai

Boucles

  • for x in liste: — Boucle sur les éléments
  • while condition: — Boucle tant que condition est vraie
  • break — Sort de la boucle
  • continue — Passe à l'itération suivante

Module 3 · Fonctions et Modules

Définir des Fonctions

Une fonction regroupe du code réutilisable :

def nom_fonction(parametres):

  • Accepte des paramètres (optionnels)
  • Retourne une valeur avec return
  • Peut avoir des valeurs par défaut
  • Supporte les *args et **kwargs

Bonnes pratiques

  • Noms descriptifs (verbes pour les actions)
  • Une responsabilité par fonction
  • Ajouter une docstring ("""...""")

Module 4 · Programmation Orientée Objet

Classes et Objets

La POO permet d'organiser le code autour d'objets avec état et comportement :

  • class NomClasse: — Définit une classe
  • def __init__(self): — Constructeur (initialise l'objet)
  • self — Référence à l'instance courante
  • Attributs — Variables de l'objet
  • Méthodes — Fonctions de l'objet

Principes POO

  • Encapsulation — Regrouper données et comportements
  • Héritage — Une classe peut hériter d'une autre
  • Polymorphisme — Même méthode, comportements différents
